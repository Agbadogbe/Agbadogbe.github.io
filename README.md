# Portfolio d'Imhotep Kakpo

Site personnel : [agbadogbe.github.io](https://agbadogbe.github.io)

Deux pages statiques en HTML et CSS, sans framework ni JavaScript :

- `index.html` : présentation, projets, compétences, parcours, contact
- `epics-viewer.html` : étude de cas du projet réalisé au CEA
- `style.css` : feuille de style commune, thème clair et sombre selon le système

Polices auto-hébergées dans `fonts/` (Newsreader et Archivo, licence SIL Open Font).

Déploiement : GitHub Pages, branche `main`.
