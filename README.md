# Portfolio d'Imhotep Kakpo

Site personnel : [agbadogbe.github.io](https://agbadogbe.github.io)

Deux pages statiques en HTML, CSS et JavaScript, sans framework ni dépendance :

- `index.html` : présentation, projets, compétences, parcours, contact
- `epics-viewer.html` : étude de cas du projet réalisé au CEA
- `style.css` : feuille de style commune, thème clair et sombre (système ou bouton)
- `main.js` : interactions (menu mobile, thème, filtres et recherche de projets, diagramme d'architecture interactif, compteurs, copie de l'e-mail). Le site reste complet sans JavaScript.

Polices auto-hébergées dans `fonts/` (Newsreader et Archivo, licence SIL Open Font).

Déploiement : GitHub Pages, branche `main`.
