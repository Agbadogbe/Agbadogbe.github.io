# Portfolio d'Imhotep Kakpo

Site personnel : [agbadogbe.github.io](https://agbadogbe.github.io)

Site statique en HTML, CSS et JavaScript, sans framework ni étape de build.

- `index.html` : accueil (assistant 3D, réalisations, projets phares) et pages Sécurité, Parcours et À propos, affichées selon l'ancre de l'URL (`#securite`, `#parcours`, `#apropos`)
- `assets/site.css` et `assets/site.js` : styles et interactions de l'accueil
- `assets/img/` : captures des projets (Onélé, API de réservation, architecture d'EPICS Viewer)
- `epics-viewer.html` : étude de cas du projet réalisé au CEA, avec `style.css`, `main.js` et les polices de `fonts/` (Newsreader et Archivo, licence SIL Open Font)
- `CV_Imhotep_KAKPO.pdf` : CV

L'avatar 3D utilise three.js (r128) chargé depuis cdnjs.

Déploiement : GitHub Pages, branche `main`.
