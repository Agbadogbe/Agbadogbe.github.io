## ✨ Présentation

Site vitrine développé et déployé **en autonomie**, présentant mon parcours, mes compétences et mes projets de développeur web full stack. L'accent est mis sur l'expérience visuelle : animations 3D en temps réel, transitions fluides au défilement et optimisation des performances de rendu.

## 🛠️ Stack technique

- **Rendu 3D** : [Three.js](https://threejs.org/) — scènes et animations WebGL en temps réel
- **Animations** : [GSAP](https://gsap.com/) + **ScrollTrigger** — séquences animées pilotées par le défilement
- **Défilement fluide** : [Lenis](https://github.com/darkroomengineering/lenis) — smooth scroll
- **Base** : HTML5, CSS3, JavaScript (vanilla)
- **Déploiement** : **GitHub Pages** (site statique)

## 🚀 Lancer en local

```bash
# Cloner le dépôt
git clone https://github.com/Agbadogbe/Agbadogbe.github.io.git
cd Agbadogbe.github.io

# Servir le site (au choix)
python3 -m http.server 8000
# puis ouvrir http://localhost:8000
```

> Le site étant statique, il suffit d'ouvrir `index.html` dans un navigateur ou de le servir avec n'importe quel serveur HTTP local.
